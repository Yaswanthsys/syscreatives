# Live QR Assets Folder (`public/live-qr/`)

This folder contains all custom image assets used by the **`/live-qr`** page. To change any image for a new event or client, simply replace the file with the same filename.

---

### Image Files:

| File Name | Purpose | Recommended Dimensions | Notes |
| :--- | :--- | :--- | :--- |
| **`children-photo.jpg`** | Main landscape event photo (or couple / birthday child) | 1200 × 750 (approx 16:9 or 3:2 landscape) | Shown in the center golden frame |
| **`invitation-card.jpg`** | Full event invitation card | High-resolution vertical image | Displayed when guests tap "View Invitation Card" |
| **`snaps-by-rajesh.png`** | Photography partner logo | Transparent PNG | Shown in the header / credits badge |

---

### How to Update for a New Event:
1. Drop your new landscape photo as `children-photo.jpg` into this folder.
2. Drop your new invitation card as `invitation-card.jpg`.
3. Drop your photographer logo as `snaps-by-rajesh.png`.
4. Refresh your browser at `/live-qr`!
